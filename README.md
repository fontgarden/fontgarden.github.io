# Font.Garden Website

The [font.garden](https://font.garden) website: the landing page, the FTGD-100 font
index with one specimen page per font, and the documentation for Font Garden and
the NeuralType (`.ntf`) font format. Built with
[Astro](https://astro.build) and Tailwind CSS, deployed to GitHub Pages on
every push to `main`.

## Develop

```
pnpm install
pnpm dev
```

## Build

```
pnpm build
pnpm preview
```

## Structure

- `src/pages/index.astro` — the landing page
- `src/components/SiteFrame.astro` — the gradient panel, the moving characters and the
  wordmark; a page changes the characters with the `field:set` event
- `src/pages/docs/` — the documentation index and chapter template
- `src/content/docs/*.md` — one Markdown file per guide chapter; frontmatter sets
  section, label, order, callout, background and next reading
- `src/content.config.ts`, `src/lib/docs.ts` — chapter schema, section and label vocabulary
- `src/layouts/DocsLayout.astro`, `src/styles/docs.css` — documentation shell and styles,
  adapted from the Google Fonts Guide (Apache-2.0)
- `src/pages/fonts/` — the FTGD-100 font index and the specimen page template
- `src/content/fonts/*.yaml` — one file per font of the index: number, name,
  classification, status, repository and summary
- `src/data/fonts/*.json`, `public/fonts/` — generated by `scripts/import_font.py`
- `src/lib/fonts.ts`, `src/styles/fonts.css` — index data, standard sample texts and styles
- `src/layouts/Layout.astro` — html/head shell
- `src/styles/global.css` — Tailwind directives, `@font-face`, base styles
- `src/styles/fonts/` — the woff2 font of the site text, a build of Virtua Grotesk
- `public/` — static assets served as-is (favicon, CNAME)

## Add or update a font in the index

The index at `/fonts/` has the numbers 00 to 99. Each font has the same
specimen page. The page shows the facts that the importer reads from the
compiled variable font.

1. Build the font in its project. The importer reads the one TTF in
   `fonts/variable/` and `OFL.txt`.
2. Run the importer with a Python that has fontTools and brotli. The
   environment of a font project has both.

   ```
   ../virtua-grotesk/.venv/bin/python scripts/import_font.py \
     --project ../virtua-grotesk --slug virtua-grotesk
   ```

3. For a new font, add `src/content/fonts/<slug>.yaml` with the next free number.
4. Run `pnpm build`.

The importer writes the WOFF2 that the pages load, the download archive (the
TTF and `OFL.txt`) and `src/data/fonts/<slug>.json`. Do not edit these files.
After each change to a font, run the importer again.

The guide chapter `src/content/docs/font-index.md` describes the index, the parts
of the specimen page and the fields of an entry.

## Keep the guide current

The guide describes the Font.Garden system: the project template
(`fontgarden/font-project-template`), the tools (`fontgarden/fgtools`),
the QA profile (`fontgarden/fontspector-fontgarden`), the tracing tools
(`img2glyph`, `img2bez`, `img2ufo`) and the reference project
(`eliheuer/virtua-grotesk`). The font index is in this repository. Those repositories are the source of the facts.

When a command, a rule, a grade or the layout changes in one of them, update
the chapter that describes it in the same session:

| change | chapter |
| --- | --- |
| a `fgtools` command or a make target | `fgtools.md`, and `build.md` or `qa.md` |
| the template or `fgtools customize` | `start.md`, `sources.md` |
| the specimen intake or the tracing tools | `specimen.md`, `tools.md` |
| mark colors and their policy | `grades.md`, `proposals.md` |
| corrections or the drafting evaluation | `learning.md` |
| a Fontspector check of the profile | `qa.md` |
| the font index, the specimen page or `scripts/import_font.py` | `font-index.md` |

`scripts/check_guide.py` compares the guide with checkouts of those
repositories. Give the path of each checkout; the example assumes they are
beside this one. It fails when a chapter names an `fgtools` command or a `make`
target that does not exist, and when a command or a template target has no
chapter. CI runs it on each push and each Monday.

```
python3 scripts/check_guide.py --tools ../fgtools \
  --template ../font-project-template --reference ../virtua-grotesk
```

Run it and `pnpm build` before a commit. A push to `main` publishes the site.
