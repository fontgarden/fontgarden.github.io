## OFL.txt

The full text of the SIL Open Font License 1.1, preceded by the copyright notice. Get the text from [openfontlicense.org](https://openfontlicense.org). The first lines look like this:

```
Copyright 2026 The Font Garden Project Authors (https://github.com/fontgarden)

This Font Software is licensed under the SIL Open Font License, Version 1.1.
This license is copied below, and is also available with a FAQ at:
https://openfontlicense.org
```

Do not add a Reserved Font Name. A fork still has to change the name under the OFL's modification terms, but the collection does not add the extra restriction. This keeps derived fonts and model outputs simple to redistribute.

The same copyright line goes into the UFO `fontinfo.plist` fields `copyright`, `openTypeNameLicense` and `openTypeNameLicenseURL`, so the compiled fonts carry it.

## AUTHORS.txt

The copyright holders, one per line, with an email or URL.

```
# This is the official list of project authors for copyright purposes.
# This file is distinct from the CONTRIBUTORS.txt file.

Eli Heuer <eli@elih.net>
```

## CONTRIBUTORS.txt

Everyone who contributed drawings, corrections or code, whether or not they hold copyright. This is the only per-person credit in the collection.

```
# This is the list of people who have contributed to this project,
# whether or not they hold copyright. See AUTHORS.txt for copyright holders.

Eli Heuer <eli@elih.net>
```

## Code, models and outputs

| item | license |
| --- | --- |
| scripts inside a source repository | OFL, together with the fonts, unless a file says otherwise |
| Runebender, font-ml, img2bez, designbot, the NeuralType engine | Apache-2.0 or MIT |
| released model weights | Apache-2.0 |
| fonts generated by a model trained on the collection | OFL |

The last line follows the OFL FAQ, version 1.1-update7, question 1.25: a font made with a model whose training data contains OFL sources is a derivative work and stays under the OFL. The FAQ says nothing about the weights themselves. For models trained on the collection's own sources the copyright holder is the project, so the project chooses Apache-2.0 for the weights.

## Foreign fonts

A foreign font may enter a repository only as a reference, in the ignored `reference-fonts` directory, and only if its license permits that use. Most foundry licenses forbid using the font software, rendered glyphs or outlines for training. The collection never uses a foreign font as a training target, so this clause is not exercised, but the reference use must still be permitted. When in doubt, use an OFL or CC0 font.
