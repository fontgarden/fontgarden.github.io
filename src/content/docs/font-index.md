## The index

The index is named FTGD-100. It has one hundred numbers, from 00 to 99, and a number without a font is an empty row. The number of a font does not change after publication.

The index page has two parts. The left part is the list. The right part is the gradient panel of the site. When the pointer or the keyboard focus is on a font, the panel shows these items in that font:

- the number and the name
- the letters of the name, which move in the panel
- the capital letters, the small letters and the figures
- the classification, the scripts, the styles, the axes, the license and the status

On a narrow screen the panel is not shown and the list is a list of links.

## The specimen page

The address of a specimen page is `/fonts/<slug>/`. The page has no layout of its own for a font. The parts are the same for each font:

| part | content |
| --- | --- |
| Name | The name of the font, as wide as the page, with the number, the classification and the status. |
| Summary | One paragraph from the entry of the font. |
| Tester | Text that the reader can change, with a control for the size and one control for each axis. A font with more than one script has one button for each script. |
| Styles | One line for each named instance of the variable font. |
| Scripts | Article 1 of the Universal Declaration of Human Rights in each script that has a standard sample. |
| Text | Articles 1 to 3 in English at 32, 20 and 14 px. |
| Characters | Each character of the font, in groups: the scripts, then figures, punctuation and symbols, and marks. |
| Information | The version, the axes, the metrics, the OpenType features, the license, the copyright line, the source revision and the download. |

The standard samples are for Latin, Arabic and Hebrew. They are in `src/lib/fonts.ts` of the website repository. A script without a standard sample is in the list of scripts and in the characters, but not in the Scripts part.

The page does not name a designer. It shows the copyright line of `OFL.txt`, which names the project. See [Post-authorship and open weights](/docs/culture/).

## The two files of a font

A font in the index has an entry and a facts file in the website repository.

The entry is `src/content/fonts/<slug>.yaml`. A person writes it. It has six fields:

| field | content |
| --- | --- |
| `number` | The number in the index, from 0 to 99. Two fonts cannot have the same number. |
| `name` | The family name. |
| `classification` | One or two words, for example Neo-grotesk or Monospace. |
| `status` | The state of the font, for example In development. |
| `repository` | The address of the source repository. |
| `summary` | A short paragraph of facts about the design. |

The facts file is `src/data/fonts/<slug>.json`. The importer writes it. It has the version, the axes, the named instances, the scripts, the characters with their Unicode names, the OpenType features, the metrics and the source revision. Do not edit this file.

## Add or update a font

1. Build the font in its project with `make build`. See [Build the fonts](/docs/build/).
2. Make sure that `fonts/variable/` has one TTF and that `OFL.txt` is at the root of the project.
3. For a new font, write the entry with the next free number.
4. In the website repository, run `scripts/import_font.py --project <project> --slug <slug>`. Use a Python that has fontTools, brotli and Pillow, for example the Python of the font project.
5. Run `pnpm build` and read the specimen page.

The importer writes four files:

- `public/fonts/<slug>/<slug>.woff2`, the font that the pages load
- `public/fonts/<slug>/<slug>.zip`, the download, with the TTF and `OFL.txt`
- `public/fonts/<slug>/<slug>.png`, the picture that a link to the specimen page shows, with the name in the font
- `src/data/fonts/<slug>.json`, the facts file

The website does not build fonts. After each change to a font, run the importer again. With `--all --projects <folder>`, the importer reads each font of the index from `<folder>/<slug>`. With `--check --projects <folder>`, it writes nothing, and it fails when the facts of a font name a revision that is not the current revision of its project. The Information part of the specimen page shows the revision of the sources that the importer read.

## The font of the site text

The text of the website is in Virtua Grotesk. The pages load the same WOFF2 that the importer writes for the index, so an import of Virtua Grotesk also changes the site text.

## The download

The download is the variable TTF and the license in one archive. The OFL requires that the license goes with the font. See [Licenses](/docs/licenses/). A font with the status In development can change in each revision.
